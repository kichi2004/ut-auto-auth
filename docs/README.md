# 筑波大学統一認証システム 自動ログイン拡張

[English version](./README_en.md)

筑波大学の統一認証システム画面を自動で入力する Chrome 拡張機能です。

## インストール方法

1. このリポジトリをクローンまたはダウンロードします
2. Chrome ブラウザで `chrome://extensions/` を開きます
3. 右上の「デベロッパーモード」を有効にします
4. 「パッケージ化されていない拡張機能を読み込む」をクリックします
5. このプロジェクトのルートディレクトリを選択します

## 使い方

### 初期設定

1. Chrome の拡張機能一覧から本拡張機能を見つけます
2. 「オプション」または「詳細」をクリックして設定画面を開きます
3. 以下の情報を入力します：
   - **UTID-13**: 13 桁の UTID-13（例: `0012026099999`）
   - **UTID-NAME**: UTID-NAME（例: `s2609999`）
     - 「UTID-13 から自動入力」ボタンで UTID-13 から自動生成できます
   - **パスワード**: 統一認証システムのパスワード
4. 「保存」ボタンをクリックします

### ログイン

設定完了後、以下のページにアクセスすると自動的にログイン情報が入力されます：

- 筑波大学統一認証システムのログイン画面（manaba 等）
- TWINS
- 情報科学類アカウントのログイン画面

## セキュリティについて

- 入力したパスワードは、拡張機能の開発者には送信されません
- Chrome の同期機能を有効にしている場合、Google アカウントに紐付けられて保存される場合があります
- パスワードは Chrome の拡張機能ストレージに保存されます
